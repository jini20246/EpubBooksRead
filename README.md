# Epub 阅读器(EpubBooksRead)
<h1>·</h1>
<h2>关于开发语言</h2>
基于turbowarp（主阅读器）+python（扩展名关联支持，朗读服务支持）开发<br>
<h2>功能</h2>
1.用于查看epub文件<br>
2.基于**dc:identifier**标签保存阅读进度<br>
3.支持进度备份/还原<br>
4.朗读（仅windows端，安卓端暂无解决方案）<br>
5.dc:identifier标签修改工具<br>
6.章节选择器（含章节名&章节内容筛选功能）<br>
7.自定义背景&部分文本颜色<br>
8.支持配置替换表（可将指定文本内容替换为另一文本指定内容）<br>
