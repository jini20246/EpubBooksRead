# Epub 阅读器(EpubBooksRead)
<h2>关于开发语言</h2>
基于turbowarp（主阅读器&章节选择器&工具）+python（扩展名关联支持，朗读服务支持）开发<br>
<h2>功能</h2>
1.用于查看epub文件<br>
2.基于<b>dc:identifier</b>标签保存阅读进度<br>
3.支持进度备份/还原<br>
4.朗读（安卓端需链接运行有朗读服务的设备）<br>
5.dc:identifier标签修改，章节内容查找工具<br>
6.章节选择器（含章节名&章节内容筛选功能）<br>
7.自定义背景&部分文本颜色<br>
8.支持配置替换表（可将指定文本内容替换为另一文本指定内容，不修改原始文件）<br>
9.自定义信息展示（窗口内的小窗口用于显示文本）
10.运行时重载Epub文件&修改默认加载Epub文件的行为
11.自定义快捷键
<h2>使用方法</h2>
1.下载并解压对应版本的软件压缩包<br>
2.启动“\epub查看器.exe”或“\index.exe”或“\.同时启动.bat”<br>
3.使用朗读前需启动“文本转语音服务.exe”<br>
<h2>注意事项</h2>
1.启用“启用朗读”时某些功能会被禁用/启用<br>
2.鼠标滚轮的上下滚动将视为“↑”/“↓”键<br>
3.“替换表”的添加需输入“JSON（键对值）”(示例输入：“{"a":"b","c":"d"}”，将被解析为：【将a替换为b,将c替换为d】)<br>
4.仅能关联epub文件且需关联至“epub查看器.exe”<br>
5.执行某些操作时窗口可能会出现亮度变化较大的情况！(！！尤其对于自定义背景色！！)
6.启动器可能会使用c++重写
